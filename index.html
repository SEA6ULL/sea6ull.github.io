SEA6ULL Repository

Add this repository to Kodi:

  1. Go to Settings → File Manager → Add Source
  2. Enter https://sea6ull.github.io and name it sea6ull
  3. Go to Add-ons → Install from zip file → sea6ull
  4. Install repository.sea6ull-1.0.0.zip
  5. Go to Add-ons → Install from repository → SEA6ULL Repository
